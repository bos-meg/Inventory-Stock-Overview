# Inventory-Stock-Overview

### Overview
This project provides a high-level analysis of inventory levels, stock movement, and product availability.

### Objective
To improve inventory management by identifying stock trends, shortages, and overstock risks.

### Key Questions
* Which products are frequently out of stock?
* Are there patterns in inventory turnover?
* Where are there risks of overstock or understock?

### Tools Used
* Excel / Python
* Data visualization
* GitHub

### Key Insights
* Identified fast-moving vs. slow-moving inventory
* Highlighted gaps in stock management
* Provided visibility into inventory health

### Impact
This analysis supports better purchasing decisions, reduces waste, and ensures product availability.
